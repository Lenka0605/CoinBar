# CoinBar 图标设计稿

工具：内置 image_gen。当前为待老板确认的预览稿，尚未更新 AppIcon.icns。

源图：coinbar-icon-source.png。运行同目录 make-app-icon.swift 可重建 Resources/AppIcon-1024.png；脚本仅校正尺寸、透明边距和圆角网格，保留生成图案。

## 生成提示词

用途：logo-brand，CoinBar macOS 菜单栏实时币价应用的全新正式 App 图标。请生成单张 1024×1024 PNG，画布外部是真透明 alpha，不要棋盘格、不加展示背景、不做样机。主体是一个位于正中的 824×824 圆角正方形（左上角约 100,100，圆角半径约185），所有图案都在这个主体内部，四周保留透明边，不要主体外阴影。

设计方向：极简、克制、鲜明，缩到32px仍一眼可认。底板为近黑的石墨色，只有极细腻的材质与轻微边缘高光，不要花纹。正中只放一个大号的定制奶白色 C 形标记：C 由一条宽厚、圆润、横向拉长的胶囊形轮廓切开右侧形成，像菜单栏中的一枚价格胶囊，几何、舒展、饱满，留白干净。标记约占底板宽度的六成，笔画足够粗壮，右侧开口清楚。开口中只放一颗清亮的翡翠绿色圆点，象征实时在线的行情；这颗点与白色C分离，有充足间距，绿色不刺眼，不发光。

设计必须以清晰的轮廓、均衡的留白和微妙的实体感取胜，正面视角，无透视倾斜，无厚重3D。整个图标只有石墨底、奶白色C和翡翠绿圆点这三个视觉元素。禁止数字、价格文字、额外字母、Bitcoin标志、美元符号、金币、K线、折线、上涨箭头、网格、窗体红黄绿按钮、霓虹光晕、水印。只生成这一枚独立成品图标，不要多方案拼图。
